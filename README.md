# Water AI Workshop

Modern responsive workshop website built with Next.js, TypeScript, Tailwind CSS, Framer Motion and Lucide React.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Theme

Edit `app/globals.css` to change the base, primary, secondary and surface colors.

## Event content

Edit `lib/event-data.ts` to update workshop information.
